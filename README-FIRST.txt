SEGMENTS + CONTINUUM — GITHUB UPDATE

This package is designed to be uploaded into the ROOT of your existing GitHub Pages repository.

REPLACE these existing files:
1. index.html
2. styles.css

ADD these new files:
3. continuum.html
4. assets/images/continuum-01.png through continuum-10.png

KEEP your existing files unchanged:
- works.js
- script.js
- all investigation images
- leisure-panorama.png
- any other existing assets

EASIEST METHOD IN GITHUB:
1. Open the repository.
2. Click Add file > Upload files.
3. Drag the CONTENTS of this folder into GitHub, not the outer folder itself.
4. GitHub will show index.html and styles.css as replacements and the Continuum files as additions.
5. Enter a commit message such as: Add Continuum archive.
6. Click Commit changes.

After GitHub Pages updates, CONTINUUM will appear in the main navigation and as a large dark transition section after Investigations.

Important: Do not delete works.js or script.js. The replacement index.html continues to use them for the existing SEGMENTS gallery and fullscreen viewer.
